# OZON

Учебное SPA с каталогом, страницами входа и регистрации. Проект собирается Vite, использует браузерные ES modules и локальный Handlebars.

## Возможности

- SPA-навигация без перезагрузки между `catalog`, `login` и `signup`;
- каталог из девяти тестовых товаров с локальными изображениями;
- переиспользуемый компонент карточки и переключение фотографий;
- отдельные правила валидации входа и регистрации;
- одинаковое отображение ошибок форм через общий модуль;
- локальные Handlebars-шаблоны и шрифт Inter без CDN.

Настоящие регистрация и авторизация не реализованы: в проекте пока нет backend API, cookies или сессий.

## Команды

```bash
npm install
npm run dev
npm run build
npm run preview
npm run lint
npm test
```

После `npm run dev` адрес приложения выводится в терминале. Production-сборка создаётся в `dist/`.

## Структура

```text
public/
├── css/main.css
├── images/
├── index.html
└── js/
    ├── components/product-card/  # переиспользуемая карточка товара
    ├── data/products.js          # данные каталога
    ├── pages/                    # catalog, login и signup
    ├── shared/forms/             # обработка форм и чистая валидация
    ├── templates/                # локальные Handlebars-шаблоны
    ├── main.js                   # точка входа
    └── router.js                 # SPA-навигация
test/
└── validation.test.js            # тесты чистых валидаторов
```

## Архитектура форм

Страница передаёт в `renderAuthPage` свой шаблон и чистую функцию валидации. Общий обработчик получает значения через `FormData`, валидатор возвращает объект ошибок, а `renderFieldErrors` отображает их рядом с полями. DOM не используется внутри валидаторов, поэтому они проверяются через встроенный `node:test`.
