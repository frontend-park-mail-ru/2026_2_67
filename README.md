# VibeMarket

Frontend интернет-магазина команды 67. Сейчас доступны каталог тестовых товаров, переключение фотографий и формы входа/регистрации с локальной проверкой полей. Backend не подключён: аккаунты не создаются, вход не выполняется. Поиск, корзина, рейтинг и отзывы отсутствуют.

## Требования

- Node.js: `^20.19.0`, `^22.13.0` или `>=24` (требование используемой версии ESLint).
- npm и современный браузер с поддержкой ES-модулей и Fetch API.

## Установка и запуск

Из корня репозитория:

```sh
npm ci
npm start
```

В PowerShell, если запрещён запуск `npm.ps1`, используйте `npm.cmd ci` и `npm.cmd start`.

Откройте адрес, указанный сервером в терминале (обычно http://localhost:8081). Остановка — `Ctrl+C`.

`npm ci` запускает `prepare`: копирует Handlebars, Inter и лицензии из npm-пакетов в `public/vendor/`. При отключённых lifecycle-скриптах выполните `npm run prepare` отдельно. Интернет нужен для установки зависимостей, но не для загрузки библиотек в браузере.

`npm start` запускает статический сервер `serve`. Сборки и горячего обновления нет: после изменения исходников обновите страницу. Через `file://` приложение не запускается — шаблоны загружаются HTTP-запросами.

## Развёртывание

Выполните `npm ci`, затем разместите **содержимое `public/`**, включая созданный `vendor/`, в корне сайта на статическом HTTP-сервере. Сервер должен отдавать JS с JavaScript MIME-типом, а `.hbs` — без подмены на `index.html`.

Команды сборки нет. Старый `dist/`, если остался, не используется и не должен публиковаться. Подтверждённый публичный адрес пока не указан.
