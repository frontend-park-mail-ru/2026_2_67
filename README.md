# OZON 


## Что реализовано сейчас

- SPA-переходы между каталогом, авторизацией и регистрацией без перезагрузки страницы;
- каталог из 9 тестовых товаров;
- одна переиспользуемая карточка товара;
- локальные изображения товаров;
- переключение фотографий в карточках с несколькими изображениями;
- формы авторизации и регистрации;
- JavaScript-валидация полей форм;
- Handlebars как шаблонизатор;
- комментарии JSDoc у основных JavaScript-функций.

## Что пока не реализовано

- backend и API;
- настоящая регистрация и авторизация;
- cookies, сессии и CORS;


## Запуск  локально

Из корня проекта запусти:

```text
npx.cmd serve -s public -l 8080
```

Затем открой в браузере:

```text
http://localhost:8080
```

```text

├── css/main.css          # стили интерфейса
