# catalog Specification

## Purpose
Каталог показывает товары, полученные из backend API, их цены и фотографии.

## Requirements

### Requirement: Загрузка каталога
Приложение SHALL запрашивать товары из backend API вместо локального тестового массива. Пока запрос выполняется, SHALL отображаться сообщение о загрузке. Каждый полученный товар SHALL отображаться в белой карточке с фотографией, ценой и названием. На настольном экране карточки SHALL располагаться в четыре колонки.

#### Scenario: Успешная загрузка
- **WHEN** API возвращает список товаров и пользователь открывает каталог на экране шириной 900 пикселей или больше
- **THEN** товары отображаются в четыре колонки с данными из ответа API.

#### Scenario: Пустой каталог
- **WHEN** API возвращает пустой список
- **THEN** вместо карточек отображается сообщение «Товары пока не добавлены».

#### Scenario: Ошибка загрузки
- **WHEN** запрос товаров завершается ошибкой или ответ не является списком
- **THEN** каталог показывает сообщение об ошибке и кнопку «Повторить» для нового запроса.

### Requirement: Переключение фотографий
Карточка с несколькими фотографиями SHALL предоставлять стрелки и индикаторы для переключения. Карточка с одной фотографией SHALL не показывать эти элементы.

#### Scenario: Выбор следующей фотографии
- **WHEN** пользователь нажимает стрелку в карточке
- **THEN** меняется фотография и активный индикатор только этой карточки, без перезагрузки страницы.

#### Scenario: Единственная фотография
- **WHEN** товар содержит одно изображение
- **THEN** карточка показывает его без стрелок и индикаторов.

### Requirement: Только реализованные действия
Каталог SHALL не показывать поиск, корзину, рейтинг и отзывы до реализации соответствующих возможностей.

#### Scenario: Просмотр доступных действий
- **WHEN** пользователь открывает каталог
- **THEN** не видит поиска, кнопок корзины, рейтинга или отзывов.
