# app-shell Specification

## Purpose
Оболочка приложения обеспечивает запуск сайта и переходы между каталогом, входом и регистрацией без повторной загрузки документа.

## Requirements

### Requirement: Запуск приложения
После успешной загрузки приложение SHALL показывать каталог. При ошибке загрузки шаблонов SHALL отображаться понятное сообщение вместо пустого экрана.

#### Scenario: Первое открытие
- **WHEN** пользователь открывает сайт и ресурсы доступны
- **THEN** отображается каталог.

#### Scenario: Недоступный шаблон
- **WHEN** один из шаблонов не удаётся загрузить
- **THEN** появляется сообщение о невозможности загрузить приложение с предложением обновить страницу.

### Requirement: Переключение экранов
Переходы между тремя экранами SHALL выполняться без перезагрузки документа и изменения URL. После обновления браузера SHALL открываться каталог.

#### Scenario: Возврат из формы
- **WHEN** пользователь нажимает «В каталог»
- **THEN** каталог заменяет форму без перезагрузки страницы.

### Requirement: Локальные ресурсы
Приложение SHALL загружать библиотеку шаблонов, шрифты и фотографии со своего HTTP-сервера без обращения к сторонним CDN.

#### Scenario: Открытие после установки зависимостей
- **WHEN** пользователь открывает подготовленный сайт
- **THEN** все ресурсы интерфейса загружаются с адреса сайта.
